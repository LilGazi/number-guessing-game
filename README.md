# Number Guessing Game 🎯

A simple Python guessing game where the computer randomly selects a number between 1 and 100 and the player tries to guess it.

## Features

- Random number generation
- User input
- Hints when the guess is too high or too low
- Repeated guessing until the correct answer is found

## Technologies Used

- Python
- `random` module

## How It Works

The program generates a random number between 1 and 100.

The player enters a guess. The program then gives a hint:

- **Too low** — the guess is below the secret number.
- **Too high** — the guess is above the secret number.

The game continues until the player guesses correctly.

## Example

```text
Guess a number from 1 to 100: 50
Too low!

Try again: 75
Too high!

Try again: 63
Congratulations! You guessed the number!
```
